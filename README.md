# Keitaro Campaign Manager (Обёртка над трекером Keitaro)

Сервис автоматизации создания и управления рекламными кампаниями в Keitaro Tracker.

Проект разработан на стеке **FastAPI + SQLAlchemy (asyncpg) + Alembic + PostgreSQL** с современным веб-интерфейсом на **HTML5 + TailwindCSS + Vanilla JS**.

---

## 🚀 Возможности

1. **Создаватор кампаний**:
   - Принимает название кампании, двухбуквенный гео-код страны (ISO2) и ID оффера.
   - Автоматически добавляет префикс фамилии (`test_strygin_`).
   - Настраивает привязку к домену (`https://kylovoa.com/`, ID 1813), группе (`VZ adrobot test`, ID 9799) и источнику трафика (`FORTESTS`, ID 836).
   - Создает **2 потока**:
     - **Поток 1 (Google)**: перехватывает посетителей из указанной страны (`country accept [GEO]`) и делает редирект на `https://www.google.com`.
     - **Поток 2 (Offers)**: направляет целевой трафик на выбранный оффер со 100% долей.
   - Поддерживает ручной ввод ID оффера и быстрый выбор из выпадающего списка.

2. **Редактор существующей кампании**:
   - Выбор любой существующей кампании из выпадающего списка.
   - Отображение конфигурации потоков (правила Google-фильтрации и статистика потока офферов).
   - Интерактивная таблица офферов в кампании.
   - Кнопка **Добавить оффер**: добавление нового оффера с автоматическим равномерным пересчетом долей (`share`).
   - Кнопка **Удалить оффер**: мгновенное удаление оффера и перераспределение весов между оставшимися офферами.

3. **База данных и аудит**:
   - Асинхронные модели SQLAlchemy 2.0 (PostgreSQL).
   - Миграции базы данных через Alembic.
   - Структурированное логирование всех операций и ошибок в файлы директории `logs/`.

## 🛠 Архитектура и стек технологий

- **Язык**: Python 3.12+
- **Фреймворк API**: FastAPI (Uvicorn)
- **ORM / СУБД**: SQLAlchemy 2.0 (AsyncIO), PostgreSQL (asyncpg), Alembic
- **Валидация**: Pydantic v2 / Pydantic Settings
- **HTTP-клиент**: HTTPX (асинхронный сессионный пул)
- **Frontend**: HTML5, TailwindCSS (CDN), FontAwesome
- **Контейнеризация**: Docker, Docker Compose (`compose.yml`)

Подробная архитектурная схема и описание связей представлены в [docs/UML.md](file:///home/u/Рабочий%20стол/testoboe4/docs/UML.md).

## 📦 Быстрый запуск через Docker Compose

Для запуска сервиса вместе с базой данных PostgreSQL выполните:

```bash
docker compose up --build -d
```

После старта:
- Веб-интерфейс доступен по адресу: **http://localhost:8000**
- Интерактивная документация Swagger API: **http://localhost:8000/docs**
- Логи контейнеров: `docker compose logs -f`

Остановка контейнеров:
```bash
docker compose down
```

## 💻 Локальный запуск (без Docker)

### 1. Подготовка окружения

Создайте виртуальное окружение и установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Скопируйте пример файла конфигурации:

```bash
cp .env.example .env
```

При необходимости отредактируйте параметры подключения к PostgreSQL (`DATABASE_URL`). Если PostgreSQL локально не установлен, можно запустить только контейнер базы данных:

```bash
docker compose up -d postgres
```

### 3. Применение миграций БД

```bash
alembic upgrade head
```

### 4. Запуск сервера

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

Сервис откроется на [http://localhost:8000](http://localhost:8000).

## 🧪 Запуск тестов

Проект покрыт автоматическими тестами (юнит-тесты бизнес-логики и интеграционные тесты с Keitaro API):

```bash
pytest -v
```

Все тесты проходят без ошибок:
- `tests/test_services.py`: проверка расчетов распределения весов (`calculate_equal_shares`), генерации безопасных alias и изменения списка офферов.
- `tests/test_api_integration.py`: полный сквозной сценарий создания кампании, проверки структуры двух потоков, добавления оффера и удаления оффера в трекере Keitaro.
